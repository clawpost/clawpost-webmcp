WebMCP counter demo

This page registers two tools the way the ClawPost web app does: a read-only quote_letter and a draft_letter that fills the visible form — and deliberately no send. In a WebMCP-enabled browser (Chrome 149+ with chrome://flags/#enable-webmcp-testing, or ChatGPT's browser) ask the built-in agent to quote or draft a letter. Without one, use the buttons below to play the agent yourself against the exact same registration path.
